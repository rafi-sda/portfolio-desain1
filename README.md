# Portfolio — Editorial Design Website

Website portfolio dengan gaya editorial: tipografi besar, layout lapang, galeri proyek, filter kategori, profil, dan kontak. Dibuat dengan HTML, CSS, dan JavaScript murni tanpa build step.

## Menjalankan secara lokal
Buka `index.html` di browser.

## Mengaktifkan GitHub Pages
1. Buka tab **Settings** pada repository.
2. Pilih **Pages** di sidebar.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch **main** dan folder **/(root)**.
5. Klik **Save**. Setelah proses publikasi selesai, situs tersedia di:
   https://rafi-sda.github.io/portfolio-desain/

## Personalisasi
- Ubah judul, deskripsi, nama proyek, kategori, dan tahun di `index.html`.
- Ganti gambar contoh dengan gambar karya Anda sendiri.
- Ganti `hello@example.com` dengan alamat email aktif.
- Sesuaikan bagian perkenalan dan daftar keahlian.
